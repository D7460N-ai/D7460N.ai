# User Experience (UX)

Apply the user's stated UX requirements to the interface. Treat the requested outcome and supplied design rules as authoritative; do not add unsolicited redesigns, explanations, or UX conventions. Preserve unrelated interface behavior and structure. If a necessary UX rule is unspecified, use the narrowest reasonable interpretation that fulfills the request.
